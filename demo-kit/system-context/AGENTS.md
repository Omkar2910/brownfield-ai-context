# system-context — agent context

Shared context for the Report Platform product. No application code lives here.
It holds what no single service owns: platform rules, contracts, cross-service OpenSpec
changes, team skills, and workspace files.

## Product map
| Repo | Role | Stack |
|---|---|---|
| report-service | Producer of /api/v1/reports/** | Spring Boot, PostgreSQL, Aspose.Cells |
| report-ui | Consumer, analyst-facing UI | Angular |
| (platform) Keycloak | Login / tokens | — |
| (platform) CIAM service | Permissions (authorization) | — |

Details: context/system-map.md

## Rules
- Platform rules in context/platform/ apply to every repo. Read them before any auth or permission work.
- contracts/<service>/ is generated by the producer's pipeline. Never hand-edit it; change the
  producer's OpenAPI instead.
- Cross-service stories get ONE OpenSpec change in openspec/changes/ here. Each code repo
  implements its slice; the producer slice goes first.
- Skills in .github/skills/ are the team's shared procedures. Change them through PRs with a
  golden-task run attached (golden-tasks/README.md).

## Checks
- Context drift: `bash scripts/check-context.sh ../report-service ../report-ui` [anchor: scripts/check-context.sh]
