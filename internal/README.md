# Internal working notes

This folder is for the kit's maintainer: briefing material, strategy, validation and open decisions. It is
**not part of the product**. The installer never copies it, and the product docs do not link to it.

> This repository is public, so anyone can read these files. They contain no company names, people's names
> or internal data, and must stay that way. Move them to a private repository before adding anything that
> should not be public.

| File | What it is for |
| --- | --- |
| [management-briefing.md](management-briefing.md) | Plain-language briefing on kit 2.0 for leadership: problem, what it does, cost, risks, the ask |
| [strategy-maturity-levels.md](strategy-maturity-levels.md) | Where the kit fits on the path from AI-assisted to AI-native delivery; the platform landscape; what to build and what not to |
| [presentation-notes.md](presentation-notes.md) | Talk track, demo order and likely questions |
| [validation-plan.md](validation-plan.md) | How to check the kit works: automated test, manual checks per tool, pilot measures |
| [context-approach-comparison.md](context-approach-comparison.md) | The kit's way of creating context compared with a generated-analysis skill; what to borrow; how to settle it on our code |
| [open-decisions.md](open-decisions.md) | Decisions still to make, with a recommendation for each |

The earlier briefing (kit 1.4) and the architecture explainer also exist as private Claude docs; this
folder supersedes the briefing for 2.0.
